- Geofenced push alerts sent to nearby verified helpers

## 🔬 Technical Architecture That Impresses

### **Tech Stack**
- **Frontend**: Next.js 14 with App Router, Bootstrap 5, Canvas API
- **Backend**: Next.js API routes, Supabase PostgreSQL
- **Blockchain**: NEAR Protocol for wallet auth and token rewards
- **AI**: Rule-based verification engine (ML-ready)
- **Verification**: World ID for human authentication
- **Storage**: Filecoin for decentralized data persistence

### **Database Schema**
```sql
users -- World ID verified, reputation scores
emergency_requests -- Privacy-first geohash locations
responses -- Who responded, when, tracking data
movement_tracking -- Anonymous geohash paths, AI analysis
action_verifications -- Multi-factor verification results
rewards -- Blockchain reward tracking, Proof Points
```

### **AI Verification Algorithm**
```javascript
confidence = (
  timeScore * 0.25 +      // Response time analysis
  locationScore * 0.30 +   // Geohash proximity
  movementScore * 0.20 +   // GPS tracking proof
  confirmationScore * 0.15 + // Mutual verification
  reputationScore * 0.10    // Historical trustworthiness
)
```
